# Voice pack Choukai JLPT

Taruh file MP3 di folder ini sesuai nama di `naskah-rekaman.csv` (kolom `nama_file`).
Contoh: `audio/choukai/n1/m1_01.mp3` = N1 問題1 1番.

Selama file belum ada, halaman Choukai otomatis memakai suara TTS browser.
`m{N}_intro.mp3` = instruksi pembuka tiap 問題 (opsional).
